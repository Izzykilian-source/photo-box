# 📸 Cute Photobox ♡ (Korean Photobooth Studio)

Aesthetic digital photobooth inspired by Korean **Life4Cuts (인생네컷)** and Purikura culture, built with React 19, Tailwind CSS v4, and Framer Motion.

![Cute Photobox](public/favicon.svg)

## ✨ Fitur Utama

- 📷 **Live Webcam Photobooth**: Hitung mundur interaktif, efek *shutter flash*, dan suara kamera mekanik asli (Web Audio API).
- 📁 **Mode Unggah Foto**: Unggah 1–4 foto dari HP / komputer, drag-and-drop, dan ganti foto per slot.
- ✂️ **Fitur Crop Interaktif**: Geser (drag), zoom in/out (80%–300%), dan putar foto 90° agar pas di frame.
- 🎨 **9 Tema Warna Estetik**:
  - 🍓 *Strawberry Milk*
  - 🍵 *Matcha Cloud*
  - 💜 *Lavender Haze*
  - 🖤 *Haru Noir*
  - 🎞️ *90s Film Roll*
  - 🎀 *Coquette Bow*
  - 🪩 *Y2K Hologram*
  - 🍑 *Peach Sherbet*
  - 🤍 *Minimal White*
- 📐 **3 Format Layout**: 4-Cut Strip (Life4Cuts), 3-Cut Strip (Classic), dan 2x2 Grid Quad.
- 🎀 **Kotak Stiker & Badge Draggable**: Emojis, karakter lucu, dan badge kata Korea yang bisa ditempel dan digeser ke posisi mana saja di strip.
- 🏷️ **Bikin Stiker Teks Sendiri**: Buat stiker badge nama/event custom dengan pilihan warna pastel.
- 📸 **8 Filter Estetik**: Normal, Soft Glow, Korean Pink, 90s Film, Warm Honey, Haru B&W, Dreamy, dan Cyber Neon.
- 💾 **Ekspor Berkualitas Tinggi**: Simpan strip foto dalam resolusi tinggi (3x pixel ratio PNG) atau salin langsung ke clipboard untuk dipaste di media sosial.
- 🔒 **100% Client-Side**: Semua pemrosesan foto terjadi di browser pengguna — tanpa server backend, aman untuk privasi, dan gratis dideploy di Vercel/Netlify.

## 🛠️ Menjalankan Proyek Secara Lokal

1. Clone repository:
   ```bash
   git clone <URL_REPO_KAMU>
   cd cute-photobox
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Jalankan development server:
   ```bash
   npm run dev
   ```

4. Build untuk produksi:
   ```bash
   npm run build
   ```

---

## 🚀 Deploy ke Vercel

1. Buka [Vercel](https://vercel.com) dan hubungkan akun GitHub kamu.
2. Pilih repository `cute-photobox`.
3. Framework Preset: **Vite** (otomatis).
4. Klik **Deploy**!
